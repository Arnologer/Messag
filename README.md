# SecureMessenger Android

Приложение для безопасного общения на платформе Android с поддержкой личных чатов, групповых бесед и обмена медиафайлами.

## 📱 Описание проекта

**SecureMessenger** — это мессенджер для Android, ориентированный на конфиденциальность и безопасность пользователей. Приложение обеспечивает защищённый канал связи для личной переписки, создания групп и обмена фото, видео и аудио сообщениями.

### Ключевые возможности

- 🔒 **Защищённый канал связи** — сквозное шифрование (E2EE) всех сообщений
- 💬 **Личные чаты** — приватная переписка один на один
- 👥 **Групповые чаты** — создание групп с настройкой прав участников
- 📷 **Фото сообщения** — отправка и получение изображений
- 🎥 **Видео сообщения** — обмен видеоконтентом
- 🎙️ **Аудио сообщения** — запись и отправка голосовых сообщений
- 🔐 **Безопасная аутентификация** — защита аккаунта пользователя
- 📴 **Работа офлайн** — кэширование сообщений при отсутствии сети

## 🛠 Технологии

- **Платформа**: Android (min SDK 21+)
- **Язык разработки**: Kotlin
- **Архитектура**: MVVM / Clean Architecture
- **Шифрование**: Signal Protocol / libsodium
- **Локальная база данных**: Room
- **Сетевой уровень**: Retrofit + OkHttp
- **Асинхронность**: Coroutines + Flow
- **DI**: Hilt / Koin
- **Медиа**: ExoPlayer, CameraX, Glide/Coil

## 🏗 Архитектура приложения

```
app/
├── data/           # Слой данных (репозитории, источники данных)
├── domain/         # Бизнес-логика (использования, модели)
├── presentation/   # UI слой (ViewModel, Fragments/Composables)
├── di/             # Внедрение зависимостей
├── utils/          # Утилиты и вспомогательные классы
└── security/       # Модуль шифрования и безопасности
```

## 🔐 Безопасность

- Сквозное шифрование всех сообщений
- Защита ключей шифрования в Android Keystore
- Верификация ключей безопасности между пользователями
- Автоматическое уничтожение сообщений (опционально)
- Защита от скриншотов в режиме инкогнито
- Двухфакторная аутентификация

## 📋 Требования

- Android 5.0 (API level 21) и выше
- Камера для фото/видео
- Микрофон для аудио сообщений
- Доступ к хранилищу для сохранения медиа
- Интернет-соединение для синхронизации
